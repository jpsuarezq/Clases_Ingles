**Producción hablada de function words.** El día donde se consolida lo que el bloque
entero venía construyendo.

La regla, ya completa: **las function words van, se aplastan y no se borran**. Tres
movimientos que se confunden fácil y que hoy toca practicar juntos.

El que las borra escribe «I gave report to manager» — error de escritura. El que las
abre enteras suena a locutor de radio de los años cincuenta. **El objetivo es el punto
medio: decir /ðə BUDget əv ðə NEW PROject/ sin que se note el esfuerzo.**

Si algo se te complica, es que estás intentando controlar cada palabra. **No.** Controlá
los picos y deja que el resto pase solo. Ese es el truco de todo el bloque.
