**Producción escrita de function words.** Y el día donde el texto revela algo incómodo:
**la mitad de lo que escribís casi no se oye**.

No es un defecto del inglés — es lo que lo hace rápido. Ocho palabras de contenido y
diez function words, y la oración se procesa sin esfuerzo. **Las function words no
compiten: ordenan.**

Para escribir eso se traduce en dos movimientos que van juntos:

**Escribí completo** — no borres artículos ni preposiciones, eso es error.
**Leé apretado** — si decís cada una entera, el texto suena a manual.

Y una regla práctica que vale para todo el plan: **si una oración tiene más de cuatro
picos, es demasiado larga**. La oración de hoy tiene ocho. No la leas: partila. Es la
escritura trabajando para la pronunciación.
