# Clases_Ingles

Espacio para guardar todo el avance de las clases de inglés.

## Contenido

| Carpeta | Qué va acá |
| ------- | ---------- |
| `notas/` | Apuntes por clase o por unidad |
| `ejercicios/` | Prácticas, worksheets, tareas |
| `recursos/` | Links, material de apoyo,material descargado |

## Conventions

- Una carpeta por unidad/tema, con el número y nombre: `unidad-01-present-simple/`
- Archivos en minúsculas con guiones: `clase-2026-03-12.md`
- Nada de credenciales ni datos personales en el repo (es público)

## Estado

Repo recién creado. La estructura de carpetas se arma a medida que agreemos contenido.
