## 3. Detalle — EF SET (recomendado)

- **URL:** https://www.efset.org/4-skill · español en `/es`
- **Gratis de verdad:** "Like all our tests, this one is **100% free**", **incluido el certificado**
  (URL + PDF). Sin verificación de identidad, sin proctor. **V**
- **Duración:** **90 minutos en una sola sesión** (no se puede reanudar). **V**
- **Habilidades:** reading, listening, writing, speaking; **writing y speaking con scoring por IA**.
  **V**
- **Ejemplo real de certificado** (https://cert.efset.org/8CKkoQ/): overall **82/100 → C2**, con
  **Reading 71, Listening 80, Writing 100, Speaking 77**, cada uno con su nivel CEFR y sus
  descriptores can-do. **V**
- **Escala:** 0–100 por skill, mapeado a CEFR A1–C2. **IELTS no se imprime en el certificado.**
  EF publica una tabla EF SET↔IELTS (B1→4.0–5.0, B2→5.5–6.5, C1→7.0–8.0, **A1/A2→n/a**).
  **V** → *si el baseline cae en A2 o por debajo, **no existe equivalente IELTS**.*
- **⚠ Reproducibilidad — el punto crítico:** "your existing certificate will be **updated** to
  reflect your latest test score" **V** → **descargar el PDF de la semana 0 ANTES de repetir**,
  o el baseline desaparece.
- **Límite: 1 test certificante cada 90 días.** 13 semanas = 91 días → **justo entra**. Un
  retest al día 88 estaría bloqueado. **V**
- EF advierte que el test "no es preciso para medir mejoras muy pequeñas". **V**
- **⚠ Acentos:** las tablas de especificación dicen *Variety = "Standard **American or British**
  variety, **without regional variants**"* **V** → **sin australiano ni neozelandés**, que es lo
  más débil contra IELTS Academic.

## 3b. Detalle — British Council EnglishScore (segunda)

- **URL:** https://www.englishscore.com · **solo móvil** (iOS/Android), cámara, proctoring por IA
- **Gratis:** "Take the Test — It's Free"; nivel CEFR y desglose de skills gratis. **El
  certificado cuesta desde US$24.99** — el paywall está en el documento, no en el score. **V**
- **Duración:** Core 30–40 min, Speaking 10–15, Writing 20–30 → "all tests in under 60 minutes".
- **⚠ Trampa:** "Unlock Speaking & Writing — **score A2 or above to access**" **V** → **si el
  nivel real está por debajo de A2, este test se vuelve de 2 skills.**
- **Acentos:** "a range of accents including **American, British, and Australian**" **V** →
  **la mejor cobertura de acentos de todo lo gratis encontrado.**
- Escala CEFR A1–C1, 100–599. Validación AI vs expertos: writing r=0.95, speaking r=0.87
  (validación propia). Retake: Core 2/24h y 10/28 días.

## 4. Lo que NINGÚN test gratis da (dicho plano)

1. **Writing y speaking con evaluador humano.** EF SET y EnglishScore puntúan con **IA**.
2. **Band oficial de IELTS.** Solo existen estimaciones. **EF SET pone "n/a" para A1/A2** — que
   es exactamente donde puede aterrizar un "A2" auto-percibido.
3. **El rango completo de acentos de IELTS.** EF SET es US-o-UK sin variantes; EnglishScore
   cubre US/UK/AU; solo el material auténtico de IELTS da el mix UK/AU/NZ/US.
4. **Curva de progreso fina de 13 semanas.** EF SET permite **1 test cada 90 días** y declara
   explícitamente que no es sensible a ganancias pequeñas.

**Por eso la estructura honesta es:** un *ancla* (EF SET 4 skills, semana 0 y 13) + un
complemento de *formato y acentos* (practice gratuito de IELTS del British Council), y
opcionalmente EnglishScore como checkpoint intermedio comparado **solo contra otro EnglishScore**.

## 5. Protocolo propuesto

| Cuándo | Qué | Qué registrar |
|---|---|---|
| **Semana 0 (día 0)** | EF SET 4 skills, 90 min, sala tranquila, Chrome, mic — https://www.efset.org/4-skill · dry run opcional 15 min: `/quick-check` | Overall 0–100 + CEFR, **los 4 scores por skill**, y la **fecha** — **descargar el PDF antes que nada** (la URL del certificado se sobreescribe) |
| **Semana 0 (opcional)** | BC IELTS Familiarisation Test o un mock IELTS Academic gratis | Resultado solo de Listening/Reading — para **formato y acentos**, **no** como baseline |
| **Semana 6–7 (interim opcional)** | BC EnglishScore (los 3 tests, gratis) | CEFR 100–599 + por skill — comparar **solo contra otro EnglishScore** |
| **Semana 13 (día ≥ 91)** | EF SET 4 skills otra vez | Delta de overall + por skill vs semana 0 (mismo instrumento, formas paralelas adaptativas, ±SEM) |
| **Durante todo** | Write & Improve (writing) / Speak & Improve (speaking) | Feedback con tag CEFR, no score de test |

**Trampas a tener presentes:**
(a) el lock de 90 días → **no** repetir en la semana 12;
(b) el certificado de EF SET **se sobreescribe** → archivar el de la semana 0;
(c) si EF SET devuelve **A1/A2, **no hay equivalente IELTS** → usar CEFR como hito principal y
tratar IELTS como direccional (A2 ≈ 3.5, B1 ≈ 4.0–5.0);
(d) si el baseline < A2, EnglishScore **no** desbloquea Speaking/Writing;
(e) ningún test gratis es proctoreado verificablemente — el certificado **no** sirve para una
institución.
